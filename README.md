## 🚀 Inicio Rápido

### Prerrequisitos

.NET 8 SDK, Visual Studio 2022 / VS Code + C# Dev Kit

### Instalación

```bash
# Clonar
git clone https://github.com/J1u2a3n8/code-smells-calculator.git
cd code-smells-calculator

mkdir build && cd build && cmake .. && make
```

### Uso

```bash
dotnet run --project src/
```

## 🧪 Tests

```bash
dotnet test
```
